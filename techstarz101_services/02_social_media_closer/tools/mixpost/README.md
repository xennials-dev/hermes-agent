# 🗓️ Mixpost (Standalone Tool Repo)

- **Role:** Self-hosted Buffer alternative for scheduling and publishing
- **Stack:** Stack B
- **Upstream Open-Source Repo:** https://github.com/inovector/mixpost (MIT)
- **Dedicated Launch Link (Auto-Boots & Opens):** http://localhost:7866/t/mixpost
- **Direct Application Port:** http://localhost:5200/mixpost

## Run Individually (One Click via Hub)
1. Start the Service #02 Hub: `python techstarz101_services/02_social_media_closer/hub/app.py`
2. Click **[http://localhost:7866/t/mixpost](http://localhost:7866/t/mixpost)** (or click the 🗓️ icon on the Hub).

## Run Individually (Standalone Docker Compose)
```bash
cd techstarz101_services/02_social_media_closer/tools/mixpost
docker compose up -d
```

## First-Run Notes
Open the link; Mixpost shows its installer/register screen for the first admin user.
