# 🤖 Steel AI Browser Sandbox (`steel-browser`)

**Stack A · Service #13: Browser-Use Web Agent (`TS101-SRV-13`)**

- **Role:** Stateful AI agent browser with persistent profiles, cookies & live session viewer
- **Upstream Repo:** https://github.com/steel-dev/steel-browser
- **License:** Apache-2.0
- **Local App URL:** http://localhost:7120/ui
- **One-Click Hub Launch Link:** `http://localhost:7877/t/steel-browser`
- **Estimated RAM:** ~1000 MB

## Run Standalone (Independent of Hub)

```bash
cp .env.example .env
docker compose up -d
```

## First-Run Notes
Watch AI browser sessions live at /ui and attach Browser-Use via ws://localhost:7120.
