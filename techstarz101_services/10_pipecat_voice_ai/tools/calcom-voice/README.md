# 📅 Cal.com Voice Booking (`calcom-voice`)

**Stack A · Service #10: Pipecat 24/7 Voice AI (`TS101-SRV-10`)**

- **Role:** Live calendar slot lookup & mid-call appointment booking API
- **Upstream Repo:** https://github.com/calcom/cal.com
- **License:** AGPL-3.0
- **Local App URL:** http://localhost:6530
- **One-Click Hub Launch Link:** `http://localhost:7873/t/calcom-voice`
- **Estimated RAM:** ~1400 MB

## Run Standalone (Independent of Hub)

```bash
cp .env.example .env
docker compose up -d
```

## First-Run Notes
Create your receptionist booking calendar and paste your Cal.com API key into Pipecat tool calls.
