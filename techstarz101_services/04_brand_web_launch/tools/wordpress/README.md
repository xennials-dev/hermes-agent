# 📝 WordPress (Standalone Tool Repo)

- **Role:** Open-source visual web builder & rapid landing page engine
- **Stack:** Stack B
- **Upstream Open-Source Repo:** https://github.com/WordPress/WordPress (GPL-2.0)
- **Dedicated Launch Link (Auto-Boots & Opens):** http://localhost:7868/t/wordpress
- **Direct Application Port:** http://localhost:5600

## Run Individually (One Click via Hub)
1. Start the Service #04 Hub: `python techstarz101_services/04_brand_web_launch/hub/app.py`
2. Click **[http://localhost:7868/t/wordpress](http://localhost:7868/t/wordpress)** (or click the 📝 icon on the Hub).

## Run Individually (Standalone Docker Compose)
```bash
cd techstarz101_services/04_brand_web_launch/tools/wordpress
docker compose up -d
```
