# Knowledge System Builder

## Trigger Conditions
Use this skill when the user says "build knowledge system", "create custom GPT",
"train AI on documents", or when a client has repetitive Q&A / email workflows.

## Instructions

### What Is a Knowledge System?

A knowledge system trains an AI on a client's documents (marketing packages, FAQs, product catalogs, SOPs) so it can answer customer and team questions automatically.

### Example Use Case: Business Brokerage

- **Problem**: Broker receives 400–500 repetitive buyer inquiries per listing.
- **Solution**:
  1. Ingest marketing and financial packages into a Custom GPT / Claude Project / Hermes RAG index.
  2. Provide prospective buyers with a dedicated knowledge link.
  3. Reduce email load by 80–90% while providing instant answers to buyers.

---

### Step‑by‑Step Implementation

1. **Gather Source Documents**:
   - Marketing packages, PDF listings, and brochures
   - FAQs & email templates
   - Product/service specifications and pricing rules
   - Internal standard operating procedures (SOPs)

2. **Build the Knowledge System**:
   - Custom GPT / OpenAI Assistant
   - Claude Project with verified artifact knowledge
   - Hermes Agent with memory providers (Honcho / Mem0)

3. **Verify Accuracy**:
   - Run adversarial testing against common boundary cases.
   - Have client sign off on responses.

4. **Deploy & Train**:
   - Provide client with direct access links.
   - Run a 30-minute team training session.
