# Process Redesign (AOA Framework)

## Trigger Conditions
Use this skill when the user says "redesign process", "optimize workflow",
"fix broken process", or when an automation fails because the underlying business logic is inefficient.

## Instructions

### The AOA Framework

$$\text{Audit} \longrightarrow \text{Optimize} \longrightarrow \text{Automate}$$

> **Guiding Principle**: Never automate a broken process. Clean up the waste first, then apply automation.

---

### Step 1: Audit (Current State)
- Map the current process step-by-step.
- Document who does what, inputs, outputs, and dependencies.
- Identify bottleneck delays, manual copy-pasting, and redundant checks.
- *Example*: A 16-step invoice approval process that can be reduced to 7 steps.

### Step 2: Optimize (Future State)
- Eliminate non-value-add steps.
- Combine overlapping verification tasks.
- Design the streamlined "To-Be" blueprint.
- Deliverable: Future-state workflow diagram.

### Step 3: Automate
- Connect APIs, webhooks, or AI agents to handle the optimized steps.
- Implement tools (Zapier, Make.com, n8n, Claude Skills, or Hermes scripts).

---

- **To-Be Process Blueprint**: Streamlined architecture
