# Hermes Knowledge System Builder

## Trigger Conditions
Use this skill when:
- Building an AI Knowledge Assistant for a business client
- Ingesting marketing packages, product specifications, SOPs, and customer FAQs
- Deploying conversational interfaces across Telegram, Discord, Slack, WhatsApp, or Web Embeds

---

## 1. High-Value Use Case: The Business Broker & Inquiry Filter

### The Problem:
A business broker or sales executive receives 400–500 emails per listing or campaign, with 90% asking the exact same 5 questions (revenue multiples, EBITDA, lease terms, employee counts).

### The Solution:
1. Ingest the confidential marketing package / CIM / listing documentation into Hermes.
2. Configure a Hermes Agent persona that acts as the broker's 24/7 technical liaison.
3. Deploy the agent onto WhatsApp, Telegram, or a gated web link.
4. Buyers interact with the Knowledge System in real time; the broker receives only pre-qualified, verified buyers ready to submit an LOI.

---

## 2. Implementation Blueprint

1. **Document Ingestion**:
   - Collect PDFs, Word docs, spreadsheets, and FAQ logs.
   - Run document cleaning and chunking.
2. **Hermes Configuration**:
   - Create system instructions and guardrails.
   - Configure gateway channels (`gateway/platforms/` for Telegram, Discord, Slack, etc.).
3. **Accuracy Verification**:
   - Run a test suite of 25 standard prospect questions.
   - Verify boundary conditions (e.g. *"I cannot disclose that without an executed NDA"*).
4. **Handoff & Client Training**:
   - 30-minute team training walkthrough.
   - Deliver shareable link and channel access.
