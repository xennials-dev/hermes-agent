# Brand Identity & Design System Rule: Xennials

## 1. Brand Guidelines
- **Brand Name**: **Xennials** (Organization: **Xennials Dev**)
- **Logo Asset**: `assets/xennials_logo.jpg` (or `/public/xennials_logo.jpg` in web applications)
- **Visual Aesthetic**:
  - Primary Logo: Luxury gold metallic script lettering with dual orbital directional swoops
  - Color Palette: Deep obsidian/charcoal background (`#0b0c0e`, `#121316`), brushed metallic gold accents (`#d4af37`, `#f3e5ab`, `#c5a059`), slate neutrals
  - Typography: Modern, refined, premium (Inter, Outfit, Plus Jakarta Sans)

## 2. Mandatory Rules for All Projects & Deliverables
1. **Always Use Xennials Branding**: Replace any placeholder names, generic logos, or default vendor branding with **Xennials** across all web dashboards, client reports, documentation, headers, footers, and CLI interfaces.
2. **Logo Placement**: Display the **Xennials** gold logo in top-left navigation headers, document title blocks, client assessment reports, and README files.
3. **Future Continuity**: This branding applies to all current and future projects, subagents, and tools created in this environment.
